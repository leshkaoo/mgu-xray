# MGU-Xray · локальная симуляция интерфейса

Откройте `index.html` в браузере. Сервер не нужен, внешние библиотеки, шрифты и сетевые запросы отсутствуют. Можно открыть на компьютере; на телефоне скачанный HTML нужно открыть именно браузером, не предпросмотром Telegram.

Это **интерактивный концепт**, не эмулятор BMW/MGU, не реальный iDrive renderer и не подключённый к Xray интерфейс. Фиктивны профили, часы, парковочный индикатор, задержка и трафик. Время сеанса считается локально. Обрыв и восстановление управляются кнопками. Без автопереподключения восстановление переводит UI в отключённое состояние для ручного запуска.

Экраны: обзор, серверы, импорт (только демо-действие, не парсер), настройки (без сохранения), диагностика. XHTTP отмечен как ещё не проверенный. Реальные конфиги и секреты вводить некуда. Переключатель автозапуска не создаёт процессов или системных настроек. Русская локаль; английская в этом макете не реализована.

Поддерживаются мышь, касание, Tab, стрелки вверх/вниз, Enter и Escape. Это моделирование фокуса в браузере, не проверка контроллера iDrive. Совместимость с реальным экраном, SDK и устройствами ввода MGU не установлена.

`capture.cjs` использует уже установленный на этом Mac Playwright Core и Chrome для проверки UI и создания кадров. Он блокирует HTTP(S)-запросы и проверяет отсутствие таких попыток и ошибок JavaScript. `output/checks.json` — фактический результат запуска. Видео собрано из кадров реального браузерного walkthrough; длительности кадров монтажные, не измерение быстродействия MGU.

Автомобиль, прокси-ядро, сетевые настройки и службы не затрагиваются. Это отдельный каталог, существующий CLI прототип не изменён.
