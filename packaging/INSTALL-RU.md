# Установка MGU-Xray 0.2.3 через MGU Store

**Экспериментальная сборка, не beta и не подтверждение совместимости с конкретным MGU.** Пакеты и формат проверены локально; на BMW установка, настоящий SDK/MainApp и откат ещё не исполнялись. Ничего на автомобиль автор проекта удалённо не устанавливал.

## Обновление с 0.2.2

Обновите источники в Store и установите обновление **MGU-Xray 0.2.3**.
Engine остаётся **0.2.2**. Удалять приложение и профиль не требуется: каталог `data/` сохраняется при штатном обновлении Store. После установки откройте приложение заново.

Исправлены подключение класса OnlineApp из SDK и порядок регистрации состояния приложения при запуске. Исправления проверены локально с синтетическим SDK-donor, не на BMW.

## Предусловия

- Уже установленный MGU Store с поддержкой catalog schema 2/source packages и `mgu-deploy >= 0.7.0`.
- iDrive 7 / Linux amd64. На iDrive 8 пакет не предназначен; совместимость ABI именно вашего блока требуется проверить.
- Уже установленный и работающий **mgu-uplink** либо отдельно проверенный интернет для UID OAP-приложения. `mguInternet: true` регистрирует приложение для существующего uplink, но не устанавливает и не настраивает его. Этот каталог не добавляет сетевую службу.
- Подготовленный собственный разрешённый профиль **VLESS TCP REALITY**. XHTTP, QR, подписки и импорт с телефона в этой версии не реализованы.
- Настройка и установка на стоянке, со стабильным питанием и доступным штатным способом удаления/восстановления. Сборка не является комплектом восстановления BMW.

## Добавление источника

В MGU Store добавьте GitHub-репозиторий:

`https://github.com/leshkaoo/mgu-xray`

Выберите канал **Releases**, не ветку `main`. Активный релиз имеет тег `catalog`.
Если Store принимает прямой HTTPS-каталог, его адрес:

`https://github.com/leshkaoo/mgu-xray/releases/download/catalog/catalog.json`

В каталоге должны появиться две позиции:

1. **MGU-Xray Engine (experimental) 0.2.2** — Xray и supervisor, без службы и автозапуска.
2. **MGU-Xray (experimental) 0.2.3** — нативный экран и контроллер. Зависимость на Engine указана в каталоге.

Установите Engine, затем приложение. Приложение распространяется как source package: Store собирает OAP bundle из собственного штатного SDK-donor на головном устройстве. BMW SDK в репозитории и публичных пакетах отсутствует. При ошибке совместимости/зависимости/SDK остановитесь на сообщении Store, не обходите его проверки и не меняйте OEM-файлы.

## Добавление профиля отдельно от установки

Без профиля приложение установится, но прокси не запустится — это ожидаемо.
Файл требуется безопасно поместить в **реальную папку данных установленного приложения**, не в каталог кода:

`<OAP-home>/data/private/profile.txt`

- OAP-home и UID берутся из фактической записи установленного `izum_mgu_xray` в Store/менеджере приложений; путь и числовой UID не угадывайте.
- Каталог `data` — настоящий каталог, владелец UID приложения, без записи для group/other.
- `private` — UID приложения, права `0700`; файл — тот же UID, права `0600`, обычный файл без symlink/FIFO, до 64 KiB.
- Содержимое — VLESS TCP REALITY URI либо поддерживаемое allowlist-подмножество Xray JSON. Не сохраняйте профиль в Git, Telegram, release asset или аргументы командной строки.
- Используйте существующий безопасный локальный/SSH-канал отдельно от водительского дисплея. Автоматического provisioning в этом релизе нет. Перед обновлением сохраняйте собственную защищённую резервную копию профиля: сохранение `data` изучено по исходникам Store, но не испытано на вашем MGU.

## Работа

Откройте **MGU-Xray** → **Запустить прокси**. Статус «движок запущен · сеть не проверена» означает работающий процесс, а не подтверждение доступности сервера.

- SOCKS5: `127.0.0.1:10808` (TCP, без UDP).
- HTTP: `127.0.0.1:10809`.
- Нужному клиентскому приложению надо явно указать этот прокси. Общесистемного VPN и автоматического изменения настроек Store/Spotify/ConnectedDrive нет.
- После скрытия экрана прокси запрашивает сохранение ACTIVE и продолжает работу; повторное открытие не запускает второй экземпляр.
- **Остановить прокси** останавливает его. Запрос shutdown от MainApp и завершение UI также останавливают supervisor.
- Автозапуск после перезагрузки/зажигания выключен. Штатные ограничения сна/MEMORY_LOW не обходятся.

## Обновление и удаление

Сначала нажмите Stop. Обновляйте согласованные Engine + app одной версии: хеши проверяются, несовпадающая пара не запускается. Удаление — штатным Remove в Store, сначала приложение, затем Engine. Никаких ручных остановок OEM-служб, изменений renderer/recmgr или firmware для этого пакета не предусмотрено. Поведение install/update/remove/rollback на вашем MGU ещё требует проверки.

## USB

Скачайте USB ZIP из релиза, распакуйте папку `mgu-repo` в корень носителя. Внутри — оба пакета, относительный каталог и контрольные суммы; это источник для существующего Store, не standalone-инсталлер и не BMW recovery image.

Отчёты и оставшиеся ограничения: `CANDIDATE.md`, `CANDIDATE_TEST_REPORT.md`, `research/RELEASE_REVIEW_0.2.2.md` в исходниках.
